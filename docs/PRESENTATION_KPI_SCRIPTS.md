# Scripts KPI prets a partager (Ville, Shop, HQ)

Ce document te sert de modele pour copier-coller un resume dans:
- email mairie / direction,
- dossier de subvention,
- note interne comite.

Remplace uniquement les valeurs entre crochets.

## 1. Script Ville (commune)

Sujet email:
`[DringDring] Bilan communal - [Mois Annee]`

Texte:

```txt
DringDring - Resume ville ([Mois Annee])

Livraisons: [X]
Beneficiaires: [X]
Commerces actifs: [X]
Subvention communale: [CHF X]
Part CMS: [X%] ([X] livraisons)
Rythme: [X] livraisons/jour actif (evol. [X%])
Impact environnemental: [X] kg CO2 evites, [X] km a velo

Lecture:
- Impact social: [phrase simple]
- Impact commerce local: [phrase simple]
- Impact budgetaire: [phrase simple]
```

## 2. Script Shop (commerce)

Sujet email:
`[DringDring] Bilan commerce - [Nom Commerce] - [Mois Annee]`

Texte:

```txt
DringDring - Resume commerce ([Mois Annee])

Livraisons: [X]
Clients actifs: [X] (nouveaux: [X])
Part CMS: [X%]
Panier moyen: [CHF X]
Evolution livraisons: [X%]

Lecture business:
- Flux commandes: [phrase simple]
- Fidelisation clients: [phrase simple]
- Contribution locale: [phrase simple]
```

## 3. Script HQ (groupe)

Sujet email:
`[DringDring] Bilan HQ - [Nom Groupe] - [Mois Annee]`

Texte:

```txt
DringDring - Resume HQ ([Mois Annee])

Groupe: [Nom HQ]
Subvention HQ: [CHF X]
Volume traite: [CHF X]
Livraisons: [X]
Subvention/livraison: [CHF X]
Part CMS: [X%] ([X] livraisons)
Clients servis: [X] | Commerces actifs: [X] | Communes couvertes: [X]
Impact vert: [X] kg CO2, [X] km a velo

Lecture direction:
- Performance operationnelle: [phrase]
- Performance sociale: [phrase]
- Performance budgetaire: [phrase]
```

## 4. Regles d'usage (qualite)

- Toujours indiquer le mois exact.
- Toujours garder le meme format de KPI.
- Ne jamais melanger des periodes differentes dans le meme resume.
- Si un KPI est vide: ecrire `0` et ajouter une phrase d'explication.

## 5. Annexes utiles au dossier

- Export CSV mensuel
- PDF facture
- Capture dashboard (ville/shop/hq)
- 1 mini cas client (impact concret)
